Run installed OSINT tools

Browser-only edition: this page can open source documentation but cannot execute tools installed on your computer.

Waiting. First check which command-line tools are installed.

Commands run on this computer only. Each run has a 90-second timeout and output cap. Amass uses passive enumeration. ZoomEye runs a real search query through the installed CLI; its API key stays in the CLI local configuration.

Local connections

Tests run in your browser against localhost. They do not run shell commands.

Ready. Enter a local HTTP endpoint and test it. A failed browser request can mean the service is stopped or the browser blocked the request.

Security note: do not expose these local services to the public internet without authentication and a deliberate security review. Keep provider/API keys in each service's configuration—not in this website's HTML.

Setup guide

Use the included Windows scripts and README to prepare local tools.

  1. Install a supported Python version, then install Sherlock and Maigret in isolated environments.
  2. Install the Amass executable separately; the supplied ZIP is source code, not a ready-to-run Windows binary.
  3. Install the ZoomEye CLI and configure your own API key locally. Never paste the key into this page.
  4. Run MiroFish as its own application. The supplied source requires Python 3.11–3.12, Node.js, and configured service credentials.
  5. Run FreeLLMAPI as its own service. Its Compose configuration binds to localhost by default; preserve that restriction unless you understand the exposure risk.
